# Solar Universe — 모션 슬라이드 웹앱

`Solar Universe` 발표자료(PPTX, 10장)를 HTML 모션 슬라이드 앱으로 변환한 결과물입니다.
원본 슬라이드의 문구는 수정 없이 그대로 옮겼고, 원본 이미지(사진·논문·기사·도식)는 슬라이드에서 잘라 WebP로 담았습니다.

## 실행
`index.html`을 브라우저로 열면 됩니다 (`assets/` 폴더와 함께 두세요).

## 조작
| 동작 | 키 / 제스처 |
| --- | --- |
| 다음 / 이전 | → ← · Space · PageUp/Down · 마우스 휠 · 좌우 스와이프 |
| 처음 / 끝 | Home / End |
| 발표노트 | N |
| 전체보기 | O |
| 전체화면 | F |
| 자동재생 | P |
| 이미지 확대 | 그림 클릭 (Esc로 닫기) |

`#slide-3`처럼 주소 끝에 붙이면 해당 슬라이드로 바로 열립니다. 폭 860px 이하에서는 슬라이드가 세로 스크롤 카드로 재배치됩니다.
